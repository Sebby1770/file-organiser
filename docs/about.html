Why this product

Disk maps answer “where?” Cleanup needs “why?”

A folder can be large because it is waste, because it contains years of valuable work, or both. File Organiser pairs visual space maps with explicit recommendation reasons and server-enforced locks, so the decision is inspectable instead of magical.

Principles

What the project is trying to earn.

Trust

State scan scope, unsigned status, limitations, and evidence without rounding them into marketing claims.

Agency

Preview first. Let the person choose. Keep personal and ambiguous files out of in-app destructive paths.

Sustainability

Keep core safety useful in source, then charge for signed delivery, updates, history, reminders, and support that genuinely exist.

Online product

No storefront or local directions.

File Organiser is distributed online through its repository and, once published, GitHub Releases. A map, street address, or local-business schema would be irrelevant and misleading, so none is included.

Work with the project

Useful feedback beats generic praise.

Bug reports should include the app version, operating system, exact non-sensitive steps, expected result, and actual result. Do not attach private file listings or exported reports. Product pilots follow the evidence template on the case-studies page.

There is no guaranteed response time during preview. Paid Pro support is intended to target a first response within two business days after launch; that is not currently an SLA.
