A Downloads folder is a crime scene. file-organiser writes a plan — by type, date, magic bytes, and the names files actually wear — then moves only if you say so. Undo is a journal, not a prayer. This page is the planner. The CLI is the desk.

What this site is

Names you type here never leave the browser. The same rules the CLI uses decide a category. On your machine, file-organiser web --folder ~/Downloads serves this page plus a live preview of the real folder.

What it does

Organize

Images, documents, ebooks, video, code, design, 3D. --magic --smart when the extension lies.

Dedupe

SHA-256 groups. Keep oldest, newest, or largest. Reclaimable bytes printed every time.

Doctor · why

Permissions, journal, empty files. why FILE prints the chain: extension, name, bytes, MIME, final.

How it can help

Landfill Downloads

preview then organize --dry-run. Recursive if the mess went deep. Age filters: --older-than 30d.

Liars

A PNG named notes.bin is still an image. Invoice in the filename is still a document.

Watch

Native events if watchdog is installed. Otherwise it polls. New files get a category without you opening Finder.

Planner

Paste names, or load a sample mess. Toggle date nests. Nothing is uploaded.

FileCategoryDestination
Load a pack or paste names.

House rules

  1. It will not organize $HOME or / unless you pass --i-mean-it.
  2. Clean and rename are dry-run until --apply.
  3. Undo lives in the folder as a journal, last ten snapshots.
  4. A feed of names on this site is a plan, not a move.

On a machine

pip install -e ".[test]"
file-organiser preview ~/Downloads --magic --smart --older-than 7d
