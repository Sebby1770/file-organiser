What this site is

This is the public desk for file-organiser, a Python CLI. The page in your browser is a planner: you paste a file list (or use the sample mess) and it shows where each file would go. Nothing on your disk moves. The real tool runs on your machine.

What it does

Preview

A plan before a move. JSON if you want a machine to read it.

Organize

Images, documents, video, code, ebooks, design files. Date nests if you ask.

Dedupe · clean · undo

SHA-256 duplicates, junk cleanup, a journal you can walk back.

How it can help

If Downloads is a landfill

One preview, then one organize. Recursive if the mess went deep.

If the extension is lying

--magic sniffs PNG/PDF/ZIP headers. --smart catches Screenshot and IMG_ names.

If you run a desk

doctor checks the folder. web serves this site locally against a live path.
