A calmer cleanup loop

Useful advice before a destructive button.

Storage tools often make “large” look synonymous with “bad.” File Organiser treats size as evidence, then adds file type, age, location, and protected-path rules before suggesting anything.

Read the decision model →
  1. 01

    Choose the scope

    Home, Downloads, or one folder. The app reports exactly which root it scanned.

  2. 02

    Read the reason

    Caches and known junk may reach Delete. Personal files and ambiguous items stay in Review or Keep.

  3. 03

    Confirm the action

    Only checked Delete rows can move through the in-app Trash flow. Review and Keep remain locked.

  4. 04

    Keep a record

    Export an explicit local JSON or CSV decision report. It contains paths, so share it carefully.

Built for trust

Safety is part of the product, not footer copy.

01

Protected-path locks

Keys, mail, photo libraries, home roots, and files in Keep cannot be trashed through the desktop API.

02

Duplicate re-checks

Potential duplicates are hashed, and checked again immediately before any eligible extra moves to Trash.

03

Preview-first organising

See proposed category moves before applying them. Existing CLI history and dry-run workflows remain available.

04

Local report export

Create JSON or CSV only when you click Export. No report is uploaded and no analytics receives its contents.

05

Local API isolation

A fresh session token, exact-origin checks, and browser security headers protect the localhost control surface.

06

Auditable rules

The recommendation code and automated tests are public, so “safe” does not have to be a black box.

Questions before you scan

Clear answers, including the awkward ones.

Does the app upload my filenames or files?

No. The desktop app serves its interface on localhost and scans the selected folder locally. There is no account or upload endpoint. An exported report does contain local paths, but it is created only when you click Export.

What does “Scan my home folder” actually cover?

Your readable home folder, not the entire physical disk. Most hidden personal folders are skipped; recognised cache folders and visible files are included. You can scan another folder or mounted volume explicitly.

Can File Organiser permanently delete something?

The desktop interface only asks the operating system to move eligible items to Trash. If that fails, the action stops and reports that nothing was deleted. Separate power-user CLI commands can support explicit permanent actions, so read their flags carefully.

Why are empty files and old installers in Review?

An empty file can be an intentional marker, and an old installer may still be needed. Age and size are clues, not proof. They stay in Review unless you decide in your file manager.

Are downloads available and code-signed?

The page checks GitHub Releases live. If there is no compatible asset, it directs you to the source install. The release pipeline can publish unsigned test builds, but trusted signed and notarised distribution still requires signing credentials and release verification.

What is free, and what will Pro add?

The MIT-licensed source preview includes local scans, advice, previews, duplicate verification, and report export. Pro is planned around signed delivery, updates, history, reminders, and support. Checkout is not live yet.

How quickly will support reply?

There is no guaranteed response time during the public preview. At paid launch, the intended Pro target is a first response within two business days. That target is not a resolution or uptime SLA.

Does the website track me?

Analytics is disabled unless the maintainer configures a provider and you opt in. The site works without consent. GitHub Pages may retain normal infrastructure logs under GitHub’s own policies.
