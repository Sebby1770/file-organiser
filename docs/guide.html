A deliberate first cleanup

Scan less. Understand more.

The fastest safe path is not a giant whole-machine sweep. Start with a folder you recognise, use the advice as evidence, and stop when something surprises you.

Step 1

Choose a bounded folder.

Start with Downloads or a test folder. “Scan my home folder” scans readable home-folder content, not every block on the disk, and skips most hidden personal directories. The path bar always shows the chosen root.

Good first target: a Downloads folder whose contents you can recognise at a glance. Poor first target: a mounted backup, photo library, or unfamiliar work folder.

Step 2

Read the advice board before the chart.

The sunburst and treemap explain where space went. They do not decide what is disposable. The decision board adds context:

BucketWhat qualifiesDesktop action
DeleteKnown regenerable caches and known junk on this scan’s advice list.Eligible for checked, confirmed OS Trash.
ReviewLarge, stale, duplicate, empty, installer, build, or ambiguous items.Locked in-app; reveal and decide yourself.
KeepPersonal libraries, code, keys, mail, photos, documents, roots, and protected paths.Locked server-side.

Step 3

Inspect one recommendation.

Click a row to see its path and reason. “Regenerable cache” means software should be able to rebuild it; it does not promise that rebuilding will be instant or free. If you do not recognise the parent application, uncheck the row.

Step 4

Treat duplicates as Review.

The Duplicates tab hashes file contents and names an explicit keeper. Before any eligible Delete-list extra can move, the app re-hashes the group. Ordinary personal-file duplicates remain Review: reveal them and choose in your file manager.

Step 5

Preview organisation moves.

The Organise tab plans category folders before moving anything. Organisation changes paths and can break shortcuts or references. Use a non-recursive Downloads preview first. Power users can use CLI dry-run and history features for more control.

Step 6

Export only when a report helps.

JSON is best for another tool; CSV is convenient for a spreadsheet. Both contain full local paths and advice reasons. They are generated locally on click, but become ordinary files once saved—store and share them accordingly.

Step 7

Confirm, then verify Trash.

Check only rows you understand. Confirm the OS Trash move. Open Trash and inspect the result before you empty it. If Trash is unavailable, File Organiser stops and leaves the source intact.

Keyboard and navigation

Small shortcuts.

  • Backspace: zoom up from a chart folder.
  • ⌘/Ctrl + B: open the native folder picker.
  • Double-click a folder slice: zoom into that folder.
  • Reveal: show the selected item in your file manager.
  • Copy path: copy the selected local path.
