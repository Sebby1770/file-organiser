Your file data belongs on your device.

This page separates the local desktop app, the public GitHub Pages site, and services you deliberately open such as GitHub issues.

Desktop app

No upload service is part of the scan.

The desktop interface is served from a loopback address on your device. Scan results, filenames, paths, sizes, hashes, and advice are processed locally. The app does not include an account, cloud sync, telemetry endpoint, advertising SDK, or remote file-upload route.

A per-launch random token and same-origin checks protect the localhost control API from unrelated websites. Security headers prevent the app from being framed and restrict scripts and network connections to itself.

Local files the app can create

Explicit reports and duplicate cache data.

  • JSON or CSV scan report: created only when you click Export. It includes full paths, filenames, classifications, sizes, and reasons.
  • .organizer_hash_cache.json: duplicate scanning can store path, size, modification time, and SHA-256 cache data in the scanned folder to speed later checks.
  • History and rule files: power-user CLI workflows may create the documented local history, rules, or report files when requested.

These files are not uploaded by File Organiser. They may still be sensitive if another sync, backup, collaboration, or indexing tool can access the folder.

Public website

Google Analytics 4 is consent-gated and disabled by default.

The repository ships with a blank GA4 measurement ID. With that blank value, no Google Analytics script or request is loaded and no consent banner is shown. If the maintainer later adds a valid G-… ID, the site asks first and loads GA4 only after an explicit opt-in stored in this browser.

The consent choice can be revisited with the “Analytics choices” footer control after analytics is configured. Desktop app events and local file data are never sent to GA4. No filename, path, hash, scan total, cleanup selection, or report content is an analytics event.

Separately, GitHub Pages and network infrastructure may process ordinary request logs such as IP address, browser information, requested page, and time under GitHub’s own policies. File Organiser does not receive raw GitHub infrastructure logs through this repository.

External actions

GitHub receives what you send to GitHub.

Source, Releases, early-access requests, issues, and discussions are hosted by GitHub. If you submit an issue, GitHub associates it with your account and the text you choose to publish. Do not include filenames, private paths, payment details, credentials, personal documents, or other sensitive information.

Payments

No checkout or payment processor is connected.

The Pro plan is pre-launch. This site cannot take payment, issue a licence, or collect billing information. A payment-specific policy, refund terms, processor disclosure, and licence terms must be published before checkout is enabled.

Control

Delete local artefacts where you created them.

You can delete exported reports and hash-cache files with your file manager. Clear this site’s local storage to remove an analytics consent choice. For a public GitHub issue, use GitHub’s edit or delete controls subject to its policies.

Questions and privacy reports can be opened through the project’s public issue tracker; avoid including sensitive data. There is no guaranteed response time during preview.
