HomeSafety

Read this before cleanup

Advice with locks, checks, and honest limits.

File Organiser reduces avoidable mistakes. It cannot know the personal value of every file, and its recommendations are not guarantees. Review selections, keep backups, and start small.

Trash is recoverable only until you empty it. The desktop app never falls back to permanent deletion if the OS Trash action fails. Emptying Trash later is a separate action and may be irreversible.

Server-enforced policy

Colour is not the safety boundary.

The interface groups results, but the local server validates every destructive request again. Hiding a button is not enough.

Delete

Known regenerable cache or junk that appears on the current advice list. You still choose the rows and confirm Trash.

Review

Large, old, duplicate, empty, installer, build output, or otherwise ambiguous. The in-app Trash routes refuse it.

Keep

Personal libraries, keys, mail, photos, documents, code, home roots, and other protected paths. Locked server-side.

Deletion sequence

Every in-app Trash action passes the same gates.

  1. The request must come from this app launch. A fresh random token and exact same-origin check reject other web pages.
  2. The target must be inside the scanned folder. Arbitrary filesystem paths are rejected.
  3. The target must not be protected. Home or drive roots, keys, mail, photo libraries, and Keep items stay locked.
  4. The target must be on the current Delete list. Review and unknown paths do not qualify.
  5. The OS Trash operation must succeed. If it fails, File Organiser reports the error and leaves the item in place.

Duplicate handling

A matching preview can go stale.

Duplicate discovery hashes file contents. Before an eligible duplicate extra can move to Trash, the app verifies the explicit keeper, re-hashes every member, confirms that nothing changed, and reapplies protected-path and Delete-list policy. If any check fails, nothing in that group is moved.

Scan scope

“Home folder” is not “the whole disk.”

The default scope is the readable home folder. Most hidden personal directories are skipped, while recognised cache directories and visible content are counted. Permission errors and files that change mid-scan can make totals incomplete. Mounted volumes and other folders must be chosen explicitly.

Remaining risks

What software cannot decide for you.

  • A cache-like folder may contain hand-created work if you used an unusual name or workflow.
  • Backups can be stale, incomplete, or inaccessible; verify important data independently.
  • OS Trash behaviour varies by filesystem, removable drive, permissions, and platform.
  • Organisation moves can break shortcuts or app references even when file contents remain intact.
  • Unsigned technical-evaluator builds may be warned about or blocked by Gatekeeper or SmartScreen.
  • Power-user CLI commands have options beyond the guarded desktop flow; preview them and read the help first.

Safer first run

A five-minute checklist.

  1. Use a small, familiar folder such as Downloads—not your entire home folder.
  2. Make sure irreplaceable files have a tested backup.
  3. Read every selected Delete reason and uncheck anything surprising.
  4. Export a local report if you want a record; remember it contains sensitive paths.
  5. Open Trash after the move and verify the result before emptying anything.
