Evidence before persuasion

No customer results have been verified yet.

That is more useful than fabricated praise. Future studies will publish what was measured, what was not, and who approved the words.

Current evidence status: zero published customer case studies and zero verified testimonials. Interface examples on the product page are labelled illustrative and are not presented as outcomes.

Pilot template

What every published study must contain.

Participant and consent
A real named person or accurately described organisation, with explicit permission for the exact public wording and an option to withdraw before publication.
Starting context
Operating system, File Organiser version, chosen scan scope, approximate file count, and any exclusions—without exposing private paths.
Baseline
Disk free space and the participant’s existing cleanup process before using the product.
Intervention
Which features were used, how long the session took, and which advice rows the participant accepted or rejected.
Measured outcome
Bytes moved to Trash, bytes actually freed after a separately confirmed Trash empty, time spent, and any false-positive or confusing recommendations.
Limitations
What cannot be attributed to File Organiser, including prior cleanup, OS behaviour, cached totals, self-reporting, or an unrepresentative test folder.
Exact participant words
A short approved quotation, never rewritten into a stronger claim.
Verification date
The date the outcome and wording were last rechecked.

Outcome rules

Bytes are not the only metric.

Safety

False positives, prevented actions, recoverability, and whether the person understood each reason.

Usefulness

Time to a confident decision, relevant findings, and recommendations the participant rejected.

Storage

Space actually recovered after deliberate Trash emptying—not an estimate presented as fact.

Participate carefully

Share product feedback, not private file data.

A pilot request can describe your operating system, rough folder type, and desired outcome. Do not publish an export, file listing, home path, username, employer material, licence key, or payment information.

Request a pilot on GitHub

Submitting an issue does not guarantee selection or a response time. No compensation or benefit should be implied unless agreed explicitly before participation.
